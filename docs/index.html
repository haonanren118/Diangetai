三步开始唱

飞牛 NAS 用原生安装包，其它主机用独立 Docker 部署包。

安装

下载 diangetai-0.0.10.fpk，在飞牛「应用中心」手动安装；Docker 主机解压部署包后执行 docker compose up -d --build。

打开大屏

电视或平板浏览器访问 http://<NAS_IP>:18090/tv，点一次「开启大屏」允许自动播放。

扫码点歌

手机扫右上角二维码，或访问 http://<NAS_IP>:18090/，搜歌后点一下即可加入队列。

把 <NAS_IP> 换成 NAS 在局域网中的地址，手机与电视保持同一局域网即可。

常见问题

安装、搜歌、切换音轨、升级，这些问题最常被问到。

点歌台是什么？可以在哪些设备上运行？

部署在 NAS 上的免费开源家庭点歌系统。推荐飞牛 NAS（fnOS）安装 fpk 原生包；任意 Docker 主机可用独立 compose 部署包。手机负责点歌，电视、平板或电脑浏览器负责大屏播放。

需要 Docker 或已 root 的安卓盒子吗？

都不需要。飞牛版是宿主直接运行 Python 3.11 标准库服务的原生应用，不依赖容器、不依赖 root 设备；只有独立部署包才使用 Docker。

手机怎么点歌？必须联网吗？

打开大屏页右上角二维码扫码即可进入手机点歌台。手机与电视处于同一局域网即可使用；在线曲库需要外网，本地曲库在纯局域网内也能播放。

支持本地歌曲、歌词和封面吗？

支持。把歌曲放进共享目录的 music 文件夹，同名 .lrc 作为歌词，同名 jpg/png 或 cover.jpg 作为封面；也可以在「曲库文件夹」页直接从手机上传。

原唱和伴奏怎么切换？

大屏或手机点「切伴奏」即可。曲库里同时放「歌名-原唱」与「歌名-伴奏」时使用真实伴奏音轨；没有配对文件时，大屏用 Web Audio 立体声反相抵消实时生成消人声伴奏。切换不打断播放进度，切歌自动恢复原唱。

升级会不会清空已点队列？

不会。关于页上传新版 fpk 可一键热更新，走正规安装链路并同步应用中心版本号，队列、歌曲与封面保留，安装失败自动回滚到备份版本。

开源协议是什么？可以商用吗？

采用 MIT 协议，允许自由使用、修改、再发行与商用，只需保留版权与许可声明。在线曲库使用第三方公开接口，音源版权归各平台所有，项目仅供个人家庭使用。

装好后歌源 / 热歌榜一直在加载中？

多见于「有 IPv6 地址、但 IPv6 出口不通」的 NAS：系统默认先连 IPv6，等 12 秒超时才回退 IPv4，一个榜单要问 4 个歌单，排队就是 40 秒起步。0.0.8 起已在应用层强制只解析 IPv4，升级并重启应用即可，不用改系统配置；也可在系统 /etc/gai.conf 写 precedence ::ffff:0:0/96 100（模板里注释掉的 10 低于 IPv6 默认的 40，不生效）。用 curl -6 与 curl -4 对比即可确认，详细排障步骤见 README。

检查更新报 Expecting value？有新版本会提示吗？

「检查更新」要填返回 JSON 的 version.json 直链；填仓库主页、Releases 网页地址拿到的是 HTML，旧版会直接把 Python 解析异常显示出来。0.0.9 起会明确提示「返回的不是 JSON」并附上响应摘要，关于页还有「使用官方更新源」一键填入。发现新版本会主动提示：手机点歌台首页出现金色提示条、关于页出现醒目文案，点击即可升级；结果缓存 6 小时，不阻塞页面，电视大屏保持纯净不打扰播放。留空并点检查更新可清除已保存的更新源，直接上传 fpk 升级。
