检查更新

留空时可在下方直接上传新版本 fpk。

不知道填什么？点 使用官方更新源 自动填入并检查。更新源必须是返回 {"version":"x.y.z", ...} 的 version.json 直链；仓库页、Releases 网页地址都不行。

在线升级 / 热更新

准备就绪。

上传新版本 fpk 后点「立即更新」，应用会自动完成停止 → 安装 → 启动，并把应用中心版本号同步为新版本；期间服务中断约 10~30 秒，已点队列、曲库和封面都不会丢失。更新失败会自动回滚。独立 Docker 部署不支持此方式，请替换部署包后重启容器。
